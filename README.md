\## Descripción



Este proyecto corresponde al taller de Gestión colaborativa de un proyecto con Git y GitHub de la asignatura Ingeniería de Software III.



La plataforma académica básica tiene como objetivo servir como estructura inicial para la gestión de información académica, utilizando Git y GitHub para el control de versiones y el trabajo colaborativo.
